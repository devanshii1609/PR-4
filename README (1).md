This Python project demonstrates data analysis and transformation techniques using **1D and 2D arrays (lists)**.

- ✅ User Defined Functions with Docstrings
- ✅ Recursion
- ✅ Lambda Functions
- ✅ Multiple Return Values

- ✅ 2D List Operations

## ✨ Features

### 📈 1D Array Analysis
- Calculate Sum
- Calculate Average
- Find Maximum Value
- Find Minimum Value
- Ascending Sorting
- Descending Sorting

### 📊 2D Array Analysis

---

## 🧩 Functions Included

### 1️⃣ analyze_1d(data)
Returns:
- Total
- Average
- Maximum
- Minimum

### 2️⃣ sort_ascending(data)
Sorts data in ascending order.

### 3️⃣ sort_descending(data)
Sorts data in descending order.

### 4️⃣ square_transform(data)
Squares all elements using Lambda.

### 5️⃣ filter_even(data)
Filters even numbers using Lambda.

### 6️⃣ recursive_sum(data)
Calculates sum using recursion.

### 7️⃣ analyze_2d(matrix)
Returns:
- Rows
- Columns
- Total Sum

### 8️⃣ row_totals(matrix)
Calculates total of each row.

### 9️⃣ sort_2d_by_column(matrix, column)
Sorts matrix according to selected column.

### 🔟 multiply_2d(matrix, factor)
Multiplies all matrix elements by a factor.

---

## 🧪 Example

```python
numbers = [10, 20, 30, 40, 50]

print(analyze_1d(numbers))
print(sort_ascending(numbers))
print(square_transform(numbers))
```

Output:
```text
(150, 30.0, 50, 10)
[10, 20, 30, 40, 50]
[100, 400, 900, 1600, 2500]
```
